⚠️ Installation Guide (Please Read)

  1. Click the "Download App" button above.
  2. Once downloaded, click on the downloaded file.
  3. If your phone says "For security reasons, your phone is not allowed to install unknown apps from this source", click "Settings" in that popup.
  4. Turn on the switch for "Allow from this source".
  5. Press the back button, and click the APK file again. The normal install screen will appear. Click "Install".

Important for old users: If you have the old version installed, you must uninstall the old version first before installing this new one.
